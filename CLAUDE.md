# Repositório "geral" do Phelipe

Projetos neste repositório:
- `audio-remix/`: app para criar mixes de competição de danças urbanas. **Antes de qualquer tarefa, leia `audio-remix/DOSSIE.md`**: tem o contexto completo, como rodar, o que já foi testado, os riscos e o protocolo de testes.

Regras rápidas (detalhes no dossiê):

- Nunca leia, mostre ou envie `audio-remix/dados/` (áudios, projetos, a chave do Google em `chave-google.txt`). O repositório é público.
- Teste de ponta a ponta antes de entregar e diga o que foi e o que não foi testado.
- Motores pagos só com a aprovação dele (o Lyria já foi aprovado).
- Branch de trabalho: `claude/sweet-brahmagupta-le71g8` (é o branch padrão).
- No PC: o repositório fica em `D:\Projetos\geral` e o Python do projeto em `D:\Projetos\remix-py\Scripts\python.exe` (Python 3.12, PyTorch cu126 para a GTX 1070 Ti).

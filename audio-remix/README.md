# Audio Remix

App para criar mixes profissionais e personalizados para coreografias de danças urbanas.

- [PLANO.md](PLANO.md): os três modos do app, o editor por contagens de 8, onde roda, motores e etapas.
- [PESQUISA-ESTILOS.md](PESQUISA-ESTILOS.md): a música de cada estilo (Breaking, Locking, Popping, Hip-Hop, House, Waacking, Vogue, Krump, Passinho).
